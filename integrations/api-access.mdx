API access lets you wire Avatar Factory into your own tools, scripts, and workflows so your code can trigger generation and publishing directly — no clicking through the app required. It's designed for creators and teams running Avatar Factory at scale, where manual operation would be a bottleneck. API access is available on the **Influencer plan only** and is set up by the Avatar Factory team on a per-account basis.

<Info>
  **API access is not the same as the Claude or ChatGPT MCP connector.** The MCP connector lets an AI assistant research trends and write scripts in chat, then hands you a link to render in the app. It works on any active Avatar Factory subscription, including the $1 trial. API access is code-level integration from your own scripts and tools — it's an Influencer-only feature and a separate setup entirely. See [Connect to Claude via MCP](/integrations/claude-mcp) if what you need is "let Claude write my scripts."
</Info>

## Plan Requirements

| Plan | API Access |
|---|---|
| Starter | Not included |
| Creator | Not included |
| Influencer | Included |

API access is included at every Influencer credit tier ($249/mo and above). On Starter and Creator plan cards, the line reads "Included on Influencer."

If you're on Starter or Creator and need API access, open **Plans** in the app and switch to Influencer. Upgrades follow the standard rules covered in the upgrade and downgrade guide.

## How to Get Access

There is no self-serve API keys screen in the app today. API access on Influencer is configured manually, one account at a time, so the first step is an email rather than a button.

<Steps>
  <Step title="Confirm your plan">
    Open **Plan & Usage** in the app and verify that your account reads **Influencer**. If it doesn't, upgrade before emailing support.
  </Step>
  <Step title="Email Support@AvatarFactory.IO">
    Write from the email address on your Avatar Factory account. Describe what you want to build and which actions your code needs to perform — for example: generating images, saving an avatar, rendering a video, publishing a post, or some combination.
  </Step>
  <Step title="Receive setup instructions">
    The support team replies within one business day with what they need from you and how your access will be configured.
  </Step>
</Steps>

## What the API Respects

Switching to API access doesn't change your plan's rules — it just changes how you call them.

- **Plan limits still apply.** Avatar caps, video models, video length, and monthly credits are set by your Influencer plan, not by how you invoke Avatar Factory.
- **Credits work the same way.** A generated image, a saved avatar, and a rendered video each cost credits at the same rates as the app. See the credits guide for the full rate table.
- **Terms of Service still apply.** Section 7 (Acceptable Use) covers automated access: you may not access the service by automated means outside the interfaces Avatar Factory provides, and you may not circumvent credit limits, plan limits, or billing. API access on Influencer is one of those provided interfaces. Scraping or probing the app is not.

<Warning>
  Instagram and TikTok direct publishing via API is **not yet live**. The app lists social connections as coming soon, and the API follows the app. Don't build a publishing workflow that depends on this before it ships.
</Warning>

Include the steps you take in the app today, and the team will tell you which of them the API covers.
