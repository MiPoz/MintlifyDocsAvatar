## How to Generate an AI Video in Claude, Step by Step

Five steps from an empty chat to a finished MP4.

### Step 1: Connect the AvatarFactory MCP

Open Claude’s Settings, go to Connectors, click Add custom connector, and paste the AvatarFactory MCP URL. Approve it. On Claude Code, add it from the terminal with a single command. The AvatarFactory tools now live in every chat.

### Step 2: Pull what is working in your niche

Ask Claude what is trending in your niche. It calls the trend tool, which draws from more than 500 million analyzed reels, and returns the hooks and formats winning right now. Starting from data beats starting from a blank prompt, because the render is only as good as the script you feed it.

### Step 3: Write the reel script

Ask Claude to write the reel in a specific persona’s voice. It builds the script on the trend data, hook to call to action. Read it, adjust a line, approve. Your first 5 scripts are free.

### Step 4: Build the avatar

Tell Claude to build the avatar that will deliver the script. AvatarFactory generates the consistent face for your persona. Your first 2 images are free, so you preview the character before committing.

### Step 5: Render the video

Say render. Claude sends the script and avatar to AvatarFactory, which produces a captioned vertical video in about three minutes. This is the render moment, and the trial starts at $1. Download the MP4 and it is ready for Reels, TikTok, and Shorts.

## Get the Most Out of Every Render

Four habits make the videos land:

- **Start from trends, not a blank prompt.** Ask what is working before you write. The render inherits whatever the script gives it.
- **Keep one persona.** Reuse the same avatar every time so the videos build a recognizable creator instead of a churn of faces.
- **Read the script before you render.** The trend data structures it, but your voice and your offer make it yours. Fix the hook first.
- **Batch in one session.** Write five scripts in a single Claude chat, then render them across the week. That is how a channel keeps a cadence.

Do those and the loop is clean: pull the trend, write the reel, build the avatar, render, publish, repeat.
