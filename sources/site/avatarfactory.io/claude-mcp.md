## Add AvatarFactory to Claude

Connecting takes about a minute on any surface where Claude supports connectors.

AvatarFactory MCP URL `https://mcp.avatarfactory.io`

### On claude.ai (web)

1. Open Settings, then Connectors.
2. Click Add custom connector.
3. Paste the AvatarFactory MCP URL: https://mcp.avatarfactory.io
4. Approve the connection. Claude now has the AvatarFactory tools in every chat.

### On Claude Desktop

1. Open Settings, then Connectors.
2. Click Add custom connector.
3. Paste the AvatarFactory MCP URL: https://mcp.avatarfactory.io

## Security and Data

For admins reviewing the connector before it reaches your team.

- Connects over OAuth 2.1 with PKCE (S256). There are no API keys to store or share.

- Plan credits are spent only on an explicit request, and rendering a video always asks for confirmation first.
