# API access on the Influencer plan

Which plan includes API access, what it is for, how it differs from the Claude and ChatGPT connector, and what to do if you want to build on AvatarFactory.

Integrations · Last reviewed September 15, 2026 · 3 min read

## What API access is

API access is listed on the Influencer plan as “Generate and publish straight from your own tools and scripts. Wire AvatarFactory into your stack.” It is meant for people who run AvatarFactory like a business and want their own code to trigger generation and publishing instead of clicking through the app.

The Starter and Creator plans show API access as not included.

## Which plan you need

| Plan | API access |
| --- | --- |
| Starter | Not included |
| Creator | Not included |
| Influencer | Included |

Every Influencer credit tier includes it. The plan cards in the app show the same line: on Starter and Creator it reads “Included on Influencer.” If you are on Starter or Creator, open **Plans** in the app and switch to Influencer. Upgrades follow the normal rules, covered in [Upgrade, downgrade, and scheduled plan changes](https://avatarfactory.io/help/upgrade-downgrade-and-scheduled-changes).

## How to get started with the API

There is no API keys screen in the app today and no public reference page. API access on Influencer is set up by hand, one account at a time, so the first step is an email rather than a button.

1. Open **Plan & Usage** and check the plan on your account reads Influencer.
2. Write to [Support@AvatarFactory.IO](mailto:Support@AvatarFactory.IO) from the email on your account. Tell us what you want to build and which actions your code needs: generating images, saving an avatar, rendering a video, publishing a post.
3. We reply within one business day with what we need from you and how your access is set up.

Sarah Johnson, for example, writes from [sarah.johnson@gmail.com](mailto:sarah.johnson@gmail.com), the email on her Influencer account, and says she wants her own scheduler to render one video a day and publish it. That is enough for us to work with.

## API access is not the connector

Two different things get called “API” by customers, so here is the split:

- **The Claude and ChatGPT connector** adds AvatarFactory to an assistant. The assistant researches trends, shapes a persona and writes scripts in the chat, then hands you a link to render in the app. It works on any active subscription, including the 1 dollar trial, on every plan. There is no key to manage. See [Add the connector in Claude or ChatGPT](https://avatarfactory.io/help/connect-to-claude-or-chatgpt).
- **API access** is for your own code, scripts and tools. It is an Influencer plan feature.

[The AvatarFactory MCP](https://avatarfactory.io/mcp) page covers the connector side in full, so you can tell which of the two you actually need.

If what you want is “let Claude write my scripts,” you do not need API access. Connect the assistant instead.

i

Whatever you build with the API spends credits the same way the app does. A generated image, a saved avatar and a rendered video each cost credits, and your monthly plan allotment applies. [How credits work](https://avatarfactory.io/help/how-credits-work) lists the rates.

## What the API does not change

- Plan limits still apply. Avatar caps, video models, video length and monthly credits are set by your plan, not by how you call AvatarFactory.
- The Terms of Service still apply. Section 7 (Acceptable Use) covers automated access: you may not access the Service by automated means outside the interfaces we provide, and you may not circumvent credit limits, plan limits or billing. API access on Influencer is one of the interfaces we provide; scraping or probing the app is not.
- Publishing to Instagram or TikTok is not live yet. The app lists social connections as coming soon, and the API follows the app.

## Questions

Write to [Support@AvatarFactory.IO](mailto:Support@AvatarFactory.IO) with the email on your account and a short description of what you are building. If you are asking whether a specific workflow is possible, include the steps you take in the app today, and we will tell you which of them the API covers.

## Frequently asked questions

Which AvatarFactory plan includes API access? +

API access is included on the Influencer plan only. The Starter and Creator plans list it as not included. If you are on one of those and want to generate or publish from your own code, upgrade to Influencer from the Plans page in the app, and the change follows the normal upgrade rules.

Is the Claude or ChatGPT connector the same thing as API access? +

No. The connector lets an assistant research trends and write scripts in the chat, and it works on any active AvatarFactory subscription, including the trial. API access is for calling AvatarFactory from your own tools and scripts, and it is an Influencer plan feature.
